# Design of Demo.Archivero

## Demo.Archivero.Frontend.Spa:

The Frontend is a single page application programmed by an AI agent, it only delivers one single html, css, js and favicon files to the browser. The whole interface is responsive to different sizes and devices.

## Demo.Archivero.Backend.Api

This project is the backend that provides all the data to the frontend application.

## User Cases:

### Login page

The first the users sees is a login screen where the user can provide his username and password, there is also a button to login.
If the log in fails, a generic error is displayed below the inputs.
Once the user logs in successfull, it hides the login page and reveals main application page.
A token is generated by the API to make API calls, the token is persisted in the browser until it experires or the user logs out.
The web method to login is app.MapPost(Routes.Login, Login);

### Main page

It consists of a collapsible left panel and a content panel on the right where other pages will be dispalyed.
The left panel works as a menu, on top are the link content pages, below the name of the current user and an option to logout.

The menu has the following link content pages:
Greeting (default)
My Archivero

Then the user clicks a link content page in the menu, the previous link content page is hidden (not removed from the DOM) and the selected one is displayed in the right panel, the option in the menus is highlighted

### Greeting content page

A blue page, with a white text that reads: "Hello Friend".

### My Archivero content page

An empty white page.
